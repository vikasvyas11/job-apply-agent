User guide

How to set the agent up once, choose a flow and a region, and turn a batch of job links into tailored CVs and cover letters in Google Docs. Updated 20 November 2026.

What it does

You paste up to ten job links. For each one the agent reads the job description, looks up the company, rewrites your master CV for that role and writes a cover letter in your voice. Both land in a copy of your Google Doc template, one tab each. The writing is done by a model running on your own computer through Ollama, so your CV is never sent to an AI company.

It drafts; you decide. Read both documents before you send anything.

Flows: one type of application per run

A flow is a complete, separate set of material for one kind of role. Each flow has its own master CV, project notes, cover letter reference and prompts.

FlowUse it forWhat its CV leads with
Data ScienceData scientist and analyst rolesAnalysis, statistics, modelling, SQL and research
GrowthGrowth, operations and founder's office rolesBuilding teams and processes, go-to-market, pricing, customers
Software DevSoftware engineering rolesSystems, stacks, architecture, testing and shipped projects

A run uses exactly one flow. Every link in that batch gets that flow's CV, notes and prompts, and the other two flows are never read, so a Growth application can't pick up Software Dev bullets or talking points. Put only one type of job link into a run: data science links in a Data Science run, and so on.

Regions: what goes on the CV's contact line

Each CV's contact line uses two placeholders, {{LOCATION}} and {{PHONE}}. When you start a run you pick a Region, and its city and phone number fill those placeholders. The app ships with two regions, UK and India; you set their details on the Setup page. Cover letters never include your location or phone number.

Set up once

  1. Install Python 3.11 or newer and Ollama.
  2. Run setup.bat on Windows or ./setup.sh on macOS and Linux.
  3. Create a Google OAuth client and a template Google Doc with two tabs named CV and Cover Letter. The setup document walks through both.
  4. Start the app with start.bat or ./start.sh. A browser tab opens at http://localhost:8501.
  5. Open Setup and work through its four tabs: Profile (your name and each region's city and phone), Documents (each flow's CV, cover letter reference, project notes and prompts), AI model and Google.

The sidebar shows what is still missing. When it reads Ready to generate, you are set.

Generate a batch

  1. On Applications, choose the Application type (the flow).
  2. Choose the Region.
  3. Paste one job link per slot. Add the company name if the page might not show it. If a site needs a login (LinkedIn often does), open Paste the job description instead and paste the text.
  4. Click Generate all.

Jobs run one after another. A progress bar fills as each one finishes, and the page refreshes itself, so there is nothing to click while you wait. Expect a few minutes per job on a laptop. You can close the tab and come back; the work continues in the background and every finished job is saved to output/runs/. Only closing the terminal window that started the app stops it.

Read the results

Each finished job appears as a sheet with a green edge for success or a red edge for a failure. It shows the role and company, an Open Google Doc button, a run log, and tabs with the tailored CV and the cover letter. Earlier batches are under Past runs, labelled with their flow and region.

Command line

The same pipeline runs without the browser:

python -m job_apply_agent --flow software --region UK --job-url "https://example.com/job"

--flow is data, growth or software; --region is any region from your settings.

Troubleshooting

What you seeWhat to do
A job fails with Your Google login has expired or is missingOpen Setup, then Google, click Connect Google account and sign in, then generate again. Google ends test-mode logins after 7 days; the agent stops instead of waiting for a sign-in nobody sees.
Your … CV is still the placeholderAdd that flow's CV under Setup, Documents.
Could not reach OllamaStart Ollama and check the model name under AI model.
A link fails to loadPaste the job description into the box under that link.
A run says InterruptedThe app was restarted mid-batch. Start the remaining links again.
An Application Control policy has blocked this file (Windows)Smart App Control blocked an unsigned python.exe. Install Python from python.org, delete .venv and run the setup script again.
