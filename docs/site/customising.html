JOB APPLICATION AGENT / DOCUMENTATION

Customising

Where each piece of your material lives, and how to change what the documents say and how they look. Updated 20 November 2026.

Content files, one folder per flow

Each flow has four plain-text files. Edit them on the Setup page (Documents, then pick the flow) or in any text editor. They are read fresh on every job, so changes apply to the next application.

FileWhat goes in it
content/<flow>/resume.mdYour complete CV for this kind of role. The model selects from it and never invents experience.
content/<flow>/project_notes.mdThe real story behind the bullets: the problem, what you did, the stack or tools, the outcome. Cover letters draw on it.
content/<flow>/coverletter_reference.mdOne letter in the voice and structure you want. Only its shape and tone are used.
content/<flow>/prompts.mdThe instructions for this flow, under three headings that must stay exactly as written: Prompt for Resume:, Prompt for Cover letter: and Writing Style:.

<flow> is data, growth or software. A fresh install copies placeholders from content.example/, and existing files are never overwritten.

Keep the flows distinct

The same job can appear in more than one flow, but each flow should describe it differently. In a Growth CV a role reads as teams, customers and commercial results; in a Software Dev CV the same role reads as systems and code. The agent guarantees a run only reads its own flow; making the material genuinely different is up to you.

Shape of a master CV

  • Line one is your name; line two is the contact line, using {{LOCATION}} and {{PHONE}}, with links as [label](https://…).
  • Section headings are ALL CAPS. Whatever headings you use, in that order, are the ones the tailored CV keeps. To drop a section, delete it from the master CV.
  • Entries are **Job Title** | Organisation, City | Mon YYYY - Mon YYYY; bullets start with * ; each entry can end with a Tools/Skills: line.
  • Keep the PROFESSIONAL SUMMARY heading: the real contact header is restored above it after generation.

Regions

Set each region's city and phone under Setup, Profile, Contact details by region. To add a region, add an entry under regions in local_settings.json; it then appears in the Region dropdown.

Change the model

Pull a model with ollama pull <name> and set its name under Setup, AI model. Larger models write better and run slower.

Change the CV layout

Spacing, font sizes, bold rules and bullet indents are tables at the top of job_apply_agent/cv_formatter.py: _SPACING_PT, _FONT_SIZE_PT, _LINE_SPACING_PCT and the bullet indent constants. Cover letter size and line spacing are in job_apply_agent/docs_writer.py. The bullet budget per role is in the LENGTH paragraph of build_cv_prompt in job_apply_agent/llm.py.

Change the look of the app

Native widget colours are in .streamlit/config.toml. Layout, type and custom pieces are in job_apply_agent/theme.css, with the palette as variables at the top. The interface uses only fonts that ship with Streamlit or the operating system, so it makes no requests to font servers.

Status and evidence — 20 November 2026

Automated tests cover per-flow seeding from content.example/, region placeholders (including an empty value), and the Setup page rendering without errors. Saving edits through the Setup page was checked by hand in a browser.
